# 健身管家 · 第一版移动端 PWA 原型

这是一个无需构建工具的移动端优先 PWA 原型，直接打开 `index.html` 即可查看源码；正式安装到 iPhone 时请通过 HTTPS 地址访问。

## 已实现

- 首页：今日训练推荐、本周节奏、训练统计
- 训练中：计时、重量/次数记录、完成组、加组、暂停/完成
- 计划：训练模板和每周安排
- 动作库：搜索、自定义动作、肌群/器械/记录类型
- 历史：累计时长、训练记录和基础统计
- 我的：健身日期日历、身高体重历史、训练统计
- 设置：浅色/深色主题、账号同步入口、训练数据/全部数据导出、训练偏好和关于信息
- 身高体重按天记录：当天最多一次，表单会预填最近值，每条记录都可以删除
- 本地保存：数据使用浏览器 `localStorage`
- 导出：在“我的 > 设置”中选择导出训练数据或全部数据
- PWA：Manifest、Service Worker、主屏幕图标
- iOS 风格导航：子页面单独返回箭头、来源页返回、沉浸式训练页和浅/深色系统色

## 在电脑上预览

在当前目录执行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 安装到 iPhone

### 推荐方式：部署到 HTTPS 静态托管

把这个目录上传到任意支持 HTTPS 的静态托管服务，例如 Vercel、Netlify、Cloudflare Pages、GitHub Pages 或自己的服务器。部署后：

1. 在 iPhone 上用 **Safari** 打开部署地址。
2. 点击底部“分享”按钮。
3. 选择“添加到主屏幕”。
4. 点击“添加”，然后从主屏幕打开“健身管家”。

它会以独立窗口打开，底部导航和本地离线缓存会保留。

### 本地局域网测试

电脑和 iPhone 连接同一个 Wi-Fi 后，可用电脑局域网 IP 访问，例如 `http://192.168.1.20:4173`。这种方式适合快速看界面；要让 Service Worker 和完整 PWA 能力稳定工作，仍建议使用 HTTPS 部署。

## 数据说明

第一版数据只保存在当前设备的浏览器本地。清除 Safari 网站数据或换设备不会自动同步。使用“我的 > 设置”中的导出功能保存 JSON 备份；后续可以接入账号和云同步。

## 后续原生 App 路线

等数据模型和交互确认后，可以用 Capacitor 把同一套 Web UI 封装成 iOS App，再接入 HealthKit、EventKit、Widget、Live Activity 和 Apple Watch。上架 App Store 需要 Mac 上的 Xcode、Apple Developer 账号和签名配置。
